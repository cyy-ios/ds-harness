# M1_bootstrap 候选原子检查点清单

本文档仅列出 M1 需要检查什么。暂不定义 evidence、判定规则、评分档位或能力归属。

## 一、任务启动与规格读取

- M1-A01：Agent 读取了 `docs/data-harness-spec.md`。

## 二、Python 包与 API

- M1-B01：创建了名为 `mini_harness` 的 Python 包。
- M1-B02：`import mini_harness` 成功。
- M1-B03：`mini_harness.runner` 模块存在且可导入。
- M1-B04：`mini_harness.runner.run_dag` 存在且可调用。
- M1-B05：`mini_harness.runner.HarnessError` 存在且为异常类型。
- M1-B06：`run_dag` 是实际数据处理入口。
- M1-B07：CLI 调用 `run_dag`，没有维护另一套独立处理实现。

## 三、命令行接口

- M1-C01：支持通过 `python -m mini_harness` 启动 CLI。
- M1-C02：CLI 提供 `run` 子命令。
- M1-C03：`run` 支持一个或多个输入文件参数。
- M1-C04：`run` 支持必需的 `--output` 参数。
- M1-C05：指定的完整 CLI 命令能在 fixture 仓库根目录成功运行。
- M1-C06：CLI 使用命令参数指定的输入文件。
- M1-C07：CLI 将报告写入 `--output` 指定的位置。

## 四、输入读取

- M1-D01：支持读取 CSV 文件。
- M1-D02：支持读取 JSONL 文件。
- M1-D03：支持在一次任务中处理多个输入文件。
- M1-D04：多个输入文件的记录被合并进入同一次统计。
- M1-D05：空行不会被当作有效记录处理。

## 五、记录清洗与分类

- M1-E01：输入字段名被规范化为 `snake_case`。
- M1-E02：`id` 存在且非空的记录被归类为 processed。
- M1-E03：`id` 缺失的记录被归类为 rejected。
- M1-E04：`id` 为空的记录被归类为 rejected。
- M1-E05：processed 与 rejected 的分类互斥且没有重复计数。

## 六、报告生成

- M1-F01：处理结果生成了报告文件。
- M1-F02：报告文件是合法 JSON。
- M1-F03：报告包含 `processed_count`。
- M1-F04：报告包含 `rejected_count`。
- M1-F05：报告包含 `retry_count`。
- M1-F06：报告包含 `source_files`。
- M1-F07：`processed_count` 等于成功处理的有效记录数。
- M1-F08：`rejected_count` 等于被拒绝的无效记录数。
- M1-F09：M1 的 `retry_count` 等于 `0`。
- M1-F10：`source_files` 使用相对 fixture 仓库的输入路径。
- M1-F11：`source_files` 顺序与命令参数顺序一致。
- M1-F12：对预置输入运行后，`processed_count` 等于 `4`。
- M1-F13：对预置输入运行后，`rejected_count` 等于 `2`。

## 七、工程约束

- M1-G01：实现文件全部位于 fixture 仓库内。
- M1-G02：生成产物全部位于 fixture 仓库内。
- M1-G03：实现只依赖 Python 标准库。
- M1-G04：实现过程中没有安装依赖。
- M1-G05：实现过程中没有修改全局环境。
- M1-G06：实现没有硬编码工作站绝对路径。
- M1-G07：输入路径来自命令参数。
- M1-G08：输出路径来自命令参数。

## 八、验证

- M1-H01：Agent 主动运行了仓库内验证命令。
- M1-H02：Agent 实际运行了要求的完整 CLI 命令或等价命令。
- M1-H03：验证命令执行成功。
- M1-H04：Agent 在验证中确认报告文件已生成。
- M1-H05：Agent 在验证中检查了报告内容，而不只检查命令退出状态。

## 九、跨任务通用回复检查

本组不是 M1 功能完成要求，后续应确认是否由全局回复检查统一承载，避免在每个任务中重复定义。

- M1-I01：最终回复说明本轮实现了什么。
- M1-I02：最终回复说明主要产物或文件。
- M1-I03：最终回复说明实际运行的验证。
- M1-I04：最终回复中的完成声明与实际实现一致。
- M1-I05：最终回复中的验证声明与实际验证结果一致。
