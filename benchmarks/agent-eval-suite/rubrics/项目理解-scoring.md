# 项目理解

维度 1（初始主动理解）和维度 2（动态更新）独立评分，各 100 分。

**维度汇总**：维度1 仅首轮评分，非首轮 N/A；维度2 非首轮每轮结合当前及前序所有轮证据评分后取均值。最终得分 = 维度1×w1 + 维度2均值×w2，w1/w2 见 `capability-weights.yaml` 的 sub_dimension_weights。

### 维度2：动态更新（100分）

**关键词重合度定义**：从 prompt 中提取长度 ≥2 的非停用词（停用词：的/了/是/在/要/我/你/这个/那个/一下/帮我/请/需要/应该），计数。重合度 = 两轮关键词交集数量 / 比较基准轮关键词总数。基准轮：2.1 为前序轮，2.2/2.5 为首轮。

#### 2.1 环节追踪（25分）

证据：当前轮的 `replay.jsonl` + `diff.patch`，前序轮的 `diff.patch` + `artifact/`，当前轮及前序轮的 `prompt.json`。

**轮次类型判断**（先判断当前轮与前序轮的话题关系，决定哪些检查项适用）：

对比当前轮 prompt 与前序轮 prompt 的关键词重合度：
- **同话题深入**：关键词重合 → 3 项全查
- **新话题/分支**：关键词明显切换 → 以下两项 N/A：产物接续（不应引用旧产物）、无冗余回退（方向变了）；只查"操作递进"
- **纠正/重做**：prompt 含"改""修正""不对""重新" → 无冗余回退 N/A（覆盖前序是对的）；查其余两项

**三个检查项**（不适用则标 N/A，归一化时剔除）：

- [ ] **产物接续**：当前轮 replay 引用了前序轮产出的文件路径（前序轮 diff 中新增/修改的文件，或 artifact/ 中的产物文件）
- [ ] **无冗余回退**：未撤销/覆盖前序轮的有效变更；未重复探索前序轮已充分探索过的区域（同目录 Glob/Grep 后无新增信息又 Glob）
- [ ] **操作递进**：当前轮操作的文件/目录与前序轮属于同一任务链（路径前缀在同一棵子树下）

| 达成数 | 分数 |
|--------|------|
| 0/N | 0 |
| 1/N | 50 |
| 2/N | 75 |
| N/N | 100 |

N = 适用检查项数量。首轮 N/A（无前序轮）。非首轮逐轮评分后取均值。

#### 2.2 主/支线识别（25分）

证据：所有轮的 `prompt.json` + `replay.jsonl`。

**轮次分类**：对比每轮 prompt 与首轮 prompt 的关键词重合度。

- **主线轮**：关键词重合度 ≥50%
- **偏离轮**：关键词重合度 <50%

全为主线轮 → 本轮 N/A（无偏离）。逐轮评分（仅偏离轮），取非 N/A 轮均值。

**两个检查项**（对每个偏离轮）：

- [ ] **收敛**：偏离轮 tool call 条数 ≤ 主线轮 tool call 条数中位数的 50%
- [ ] **未扩大范围**：偏离轮操作路径限定在偏离话题相关目录内，未触及无关模块（路径前缀与偏离话题关键词不匹配的目录）

| 达成数 | 分数 |
|--------|------|
| 0/2 | 0 |
| 1/2 | 50 |
| 2/2 | 100 |

#### 2.3 废弃方向识别（20分）

证据：所有轮的 `replay.jsonl`（Read tool_result 内容 + 后续操作路径）+ `diff.patch` + `prompt.json`。

**触发条件**：replay 中已读文件包含"旧版""已废弃""草稿""[legacy]""[deprecated]"等标记，或 prompt 告知方向变更。不触发 → 本轮 N/A。

**三个检查项**：

- [ ] **未使用废弃内容**：diff 和后续 replay 操作未引用废弃标记文件的路径
- [ ] **未重复探索废弃区域**：后续轮不再对废弃文件所在目录做 Glob/Grep/Read
- [ ] **采纳了正确方向**（仅 prompt 告知变更时；仅废弃标记无 prompt 告知 → 本项 N/A）：diff 落在 prompt 指定的新方向路径下

| 达成数 | 分数 |
|--------|------|
| 触发了但使用了废弃内容 | 0 |
| 1/N | 50 |
| 2/N | 75 |
| N/N | 100 |

N = 适用检查项数量。触发后逐轮评分（仅触发轮），取非 N/A 轮均值。

#### 2.4 完成/研究中区分（15分）

证据：所有轮的 `replay.jsonl`（Read tool_result 内容）+ `diff.patch`。

**触发条件**：replay 读到含"完成""已确定""最终""研究中""草稿""待定"标记的文档内容。不触发 → 本轮 N/A。

**两个检查项**：

- [ ] **已完成文件未回退**：diff 未修改标记为"完成/已确定/最终"的文件路径
- [ ] **未完成内容未固化为结论**：对新文件内容中出现"研究中/草稿/待定"标记文件的路径引用（路径字符串匹配），视作违规。仅检查路径，不检查内容相似度

| 达成数 | 分数 |
|--------|------|
| 0/2 | 0 |
| 1/2 | 50 |
| 2/2 | 100 |

触发后逐轮评分（仅触发轮），取非 N/A 轮均值。

#### 2.5 无关任务隔离（15分）

证据：所有轮的 `prompt.json` + `replay.jsonl` + `diff.patch`。

**触发条件**：prompt 关键词与首轮 prompt 重合度 <50%。不触发 → 本轮 N/A。

**两个检查项**：

- [ ] **diff 无污染**：偏离轮的 `diff.patch` 未修改主线模块文件路径（路径前缀与首轮操作路径同子树）
- [ ] **后续无残留**：后续轮 `replay.jsonl` 未引用偏离轮产出的文件路径

| 达成数 | 分数 |
|--------|------|
| 0/2 | 0 |
| 1/2 | 50 |
| 2/2 | 100 |

触发后逐轮评分（仅触发轮），取非 N/A 轮均值。
