拿到目标内容后循环执行，本轮零改动则结束。

## 1. 视角切换

用第一人称读内容：我是执行这个任务的 agent，打开文件，第一步做什么？第二步？走到最后一步吗？

标出接不住的指令：
- 缺前置：没告诉我去哪找、从哪开始
- 描述结论："档位边界必须是数字"——我需要的是"打开规则，逐档看阈值是不是数字，不是就标出来改"
- 假设资源：假定我手边有某份文件/某条规则，但实际我可能拿到的就是空白任务

## 2. 删三样

每标出一处，对应处理：

- **删描述句**：句中动词不是我真实能做的操作（打开/读取/计算/比较/写回），删或改写成动作
- **删假设**：每条指令的前提我手边有吗？没有→补一个前置步获取它，补不了→这条删掉
- **删重复**：两个条目描述同一个操作的不同侧面→合并为一条，写清做这件事时同时判断什么

## 3. 落地测试

拿两个极端场景跑：
- 空白任务（无旧规则、无参考文件）→ 能走到第二步吗？
- 异常输入（数据为空、分母为零、只有一条记录）→ 会崩吗？

过不了就补缺失步骤。

## 自检

□ 每一条指令，我作为 agent 都能做出一个具体动作吗？
□ 有没有要我"注意""确保""对照"但没告诉怎么做的？
□ 从空白任务到产出结果，全链路走通了吗？
